The problem

Paper records. Unconnected hospitals. Same drug, two names.

  • Patients in Sri Lanka collect prescriptions and labs across years and providers.
  • No shared EHR. A warning on one visit is forgotten at the next.
  • Paracetamol and acetaminophen are the same molecule — easy to miss on a page.

What we built

Upload a folder of paper. Get one timeline of risk.

1. Vision extraction

Image → canonical JSON. Null instead of a guess.

2. Code does the math

Dates, generics, duplicates, class, lab drift. LLM never does arithmetic.

3. Independent check

openFDA confirms interactions. Unverified findings stay, labelled as such.

How we know it is not made up

Every claim carries its evidence.

  • Typed JSON schema. One retry, then fail. Placeholders stay generic-name null.
  • Identical files are cached by SHA-256 — not reported as a double dose (Y2).
  • 95.1% field accuracy on the demo model. We refused prompt fixes that dropped that to 92%.
